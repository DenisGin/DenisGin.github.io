Privacy Policy

Rclone Server Backup is a private backup automation application.

The application uses Google Drive access to upload, list, and delete backup files in the authorized account.

Backup files are transferred directly from the local server to Google Drive.

OAuth credentials are stored locally on the server and are not published on this website.

This website does not collect backup data or authentication tokens.

Personal data is not sold or used for advertising.

Access can be revoked through Google Account security settings.
